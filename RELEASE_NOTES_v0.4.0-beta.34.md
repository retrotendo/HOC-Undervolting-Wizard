# v0.4.0-beta.34

UI wording and reset-placement refinement.

- Setting pages now show `+ : Known stable / Skip to next value`.
- Removed the Reset hint from the top-right header.
- On normal Wizard pages, `- : Reset` is shown three blank lines below the final action.
- Automatic-setting confirmation now uses correct singular/plural wording:
  - one setting: `Confirm - set value`
  - Preparation/multiple settings: `Confirm - set values`
- The setting-not-ready page likewise uses `value` or `values` correctly.
- No tuning, boot-search, voltage-scan, or stress-test logic changed.
