# HOC Undervolting Wizard v0.4.0-beta.43

## First graphical interface beta
- Repackages the new minimal fullscreen GUI under the updater-compatible beta version scheme.
- Keeps the complete v0.4.0-beta.42 tuning and validation logic.
- Adds the right-side Current Instruction panel and Actual Active Values panel.
- Active values that disagree with the currently requested Horizon OC setting are highlighted in red.
- Keeps the existing beta42 guide wording and controller actions in the left pane.
- Adds the top progress strip and subtle active-step animation.

## Update compatibility
- Version number is `0.4.0-beta.43` so existing `0.4.0-beta.42` installations can detect and install it with the built-in updater.
